# 모여봐요

일정 잡기 서비스 "모여봐요" 서비스(현재 운영 중)
<h1>https://www.moyeobwayo.com</h1>

---

## 목적
- 간편한 사용을 통한 낮은 접근성, 리마인드 메시지와 사용자 중심 UI를 통해 일정조율을 간단하게 해결

---

## 주요 기능
1. **모임 일정 생성**  
   - 사용자가 원하는 기간을 선택하여 모임 일정 생성
2. **일정 선택**  
   - 만들어진 모임 안에서 간단한 UI를 통해 가능한 일정 선택
2. **알림**  
   - 확정된 모임 일정을 카카오톡으로 알림
---
